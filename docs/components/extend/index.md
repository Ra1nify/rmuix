# Extend Components

`rmuix-extend` holds the components that have **no ColorOS counterpart**. Everything here is built from
the library's ColorOS design tokens (colours, typography, shapes) but cannot claim a stock metric, because
there is nothing in the three decompiled ColorOS trees to measure. Each page says so explicitly.

| Component | Description | Notes |
| :--- | :--- | :--- |
| [ColorPicker](../media/colorpicker) | Colour picker + colour preference row | No ColorOS colour-picker class exists |
| [ImageCropper](../media/imagecropper) | Pan/zoom image cropper with a fixed viewport | No ColorOS crop component exists |
