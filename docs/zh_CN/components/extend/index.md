# Extend 组件

`rmuix-extend` 放**没有 ColorOS 对应物**的组件。这里的一切都用本库的 ColorOS 设计令牌（颜色、字体、形状）搭建，
但不能声称有官方度量——三棵 ColorOS 反编译树里没有可测量的东西，每个页面都会写明这一点。

| 组件 | 说明 | 备注 |
| :--- | :--- | :--- |
| [ColorPicker](../media/colorpicker) | 取色器 + 颜色偏好行 | ColorOS 没有取色器类 |
| [ImageCropper](../media/imagecropper) | 平移/缩放的固定视口裁剪器 | ColorOS 没有裁剪组件 |
